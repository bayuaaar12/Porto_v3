# 🚀 Porto_v3 - Personal Portfolio Website

Welcome to my personal portfolio repository! Built with modern web technologies, this site showcases my background, working experience, technical skills, and featured projects.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)

---

## ✨ Features

- 🎨 **Doodle & Neo-brutalism Design System:** Modern visual layout with custom accent highlights and responsive interactive cards.
- 📱 **Fully Responsive:** Seamless design and UI experience across desktop, tablet, and mobile devices.
- 💼 **Experience & Projects Showcase:** Highlighted breakdown of IT infrastructure, support experience, and software projects.
- ⚡ **Performance Optimized:** Fast server-side rendering and static page optimization powered by Next.js.

## 💻 Getting Started Locally

### Prerequisites

Ensure you have **Node.js 18+** and **npm** installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/bayuaaar12/Porto_v3.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd Porto_v3
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.
